# UrbanSense 展示网站

纯静态 HTML/CSS/JS，无构建依赖。尚未部署。

本地：在此目录执行 `python -m http.server 8765`，打开 http://localhost:8765 。也可直接打开 index.html。

GitHub Pages：将 index.html、style.css、app.js、assets 和 .nojekyll 上传到 UrbanSense 仓库根目录，在 Settings → Pages 选择 Deploy from a branch，main / (root)。预期路径为 https://yandisyn.github.io/UrbanSense/ ，以实际部署结果为准。

真实截图来自项目说明文档，视频与模型包来自原始提交材料。交互使用合成数据与预设流程，不提供在线 Agent。28,390 节点与预测时域为材料所述能力。模型包不含完整平台及私有数据，需自行提供数据才能运行。原代码包未声明许可证，此页面不额外赋予开源许可证。
